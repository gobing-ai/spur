# H84: sp command consolidation: --all batch variants and one dev-find lens command

## Goal

Cut the sp command surface where variants duplicate a base command: each `*all` command becomes `--all` on its base, and the four `dev-find-*` commands become one `dev-find <lens>`, with no lost behavior.

## Scope

**In scope**
- `dev-run --all` absorbs `dev-runall` (the batch schedule becomes `--schedule <sequential|parallel|auto>` because `dev-run --mode <full|implement>` already owns `--mode`); `dev-refine`, `dev-verify`, `dev-wrap` absorb their `*all` siblings.
- `dev-find <conflict|issue|next|way>` absorbs `dev-find-conflict`, `dev-find-issue`, `dev-find-next`, `dev-find-way` as a pure routing shell: lens args pass verbatim to the owning skill, and the `way` lens keeps its worktree lifecycle.
- Old command files remain for one release as thin redirects naming the replacement; AGENTS.md routing, plugins/sp/README.md, init templates and the app-layer name consumers (`dogfood/pipeline-detect.ts`, `task-readiness.ts`, `idea-handoff.ts`) updated.

**Out of scope**
- Merging commands whose contracts differ beyond batch scope.
- Changing workflow YAML behavior.
