# F73: Planning Board query convergence and actionable daily readiness

## Goal

Give the operator consistent planning reads, reliable live updates, and deterministic next actions through the existing Board and CLI contracts with less custom transport and state code.

## Scope

In scope: W3 shared validated planning transport, one planning subscription and deterministic readiness in existing task/feature surfaces.

Out of scope: process/history stream changes, new public command nouns, model-driven readiness, unapproved query-library installation, or replacement Board frameworks.

W3: migrate feature/plan/design procedure families to installed oRPC contracts, centralize planning-event subscriptions and invalidation, and add readiness/blockers/paused-work context to existing planning surfaces. Consume complete-corpus diagnostics. Keep process/history streams separate and preserve drafts, errors, cancellation, and keyboard access. No new noun or model-driven readiness.
