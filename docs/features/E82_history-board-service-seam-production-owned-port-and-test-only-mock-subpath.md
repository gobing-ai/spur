# E82: History Board service seam: production-owned port and test-only mock subpath

## Goal

The `HistoryBoardService` port is owned by production code, and the deterministic History Board mock stops
shipping through the `@gobing-ai/spur-app` root barrel. Today the live implementation imports its own
contract from the test double (`history-board-service.ts:86` → `history-board-mock-service.ts:21`) and
the root barrel re-exports the 1,321-line mock plus its fixture catalogs (`src/index.ts:258-259`), so a
test fixture is part of the production surface and of the Worker bundle.

Source: `/sp:dev-review packages --focus all` (2026-09-25), architecture candidate C1 (wrong seam).
