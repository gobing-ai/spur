# F961: Residual-scan ignores placeholder no-finding review rows

## Goal

The residual sweep counts only real review findings. A clean review whose rows read "None found (…)" or "No findings." must not fold a clean verdict to PARTIAL. A real finding that happens to begin with "None" must still count.

## Scope

**In scope**

- Widen the shared placeholder "no finding" matcher in `plugins/sp/scripts/residual-scan.ts` (used by `parseReviewFindings`).
- Regression test in `plugins/sp/tests/residual-scan.test.ts` for placeholder rows and "None of …" findings.
- Regenerate the shipped `plugins/sp/scripts/residual-scan.mjs` from the `.ts` source.

**Out of scope**

- A structured "no findings" marker in the `## Review` schema. That changes the review coordinator's contract.
- Rewriting existing task `## Review` sections.
- Matching other free-text phrasings (e.g. "Nothing to report"). They fail safe, toward blocking.
