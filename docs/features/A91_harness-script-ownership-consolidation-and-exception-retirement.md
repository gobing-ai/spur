# A91: Harness script ownership consolidation and exception retirement

## Goal

Make Spur the single implementation owner of reusable harness behavior, with explicit, small host/skill adapters and repository-only tooling. Refine and enforce ADR-130 rather than multiplying script surfaces. Operator requirement: 2026-10-11 sp-dev-idea invocation; investigation and migration: docs/plans/2026-10-11-harness-script-consolidation.md.

## Scope

In: placement policy and enforcement, complete non-test TypeScript inventory, hook entries/helpers/tests, skill adapters/lib, eval relocation, noun-owned readiness/receipts/run state/analytics, generated runtime exceptions, legacy and stale gate-lock cleanup. Out: unapproved public CLI changes, new generic nouns, implementation during ideation, deleting historical evidence, removing actual correctness gates or SQLite busy retries, unrelated current working-tree edits. Existing repo build/package policy remains repository-owned.
