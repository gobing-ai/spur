# A331: Verified offline migration artifacts and safe upgrades

## Goal

Keep offline migration build artifacts authoritative and upgrade-compatible while removing verified duplicate SQL ownership only when parity evidence justifies it.

## Scope

In: Conditional W7: persistence plumbing includes a fixture-only migration ownership/parity investigation and, only on a go decision, single-source embedded SQL. Preserve all released migration IDs/checksums, column guards and offline binaries. Do not migrate real project data as an experiment or squash history.

Out: live database experiments, rewritten migration history, schema squashing, new public verbs, unapproved dependency changes, unrelated release tooling or signing.
