# B21: Executor tier policy as a leaf module

## Goal

The capability-tier policy — `getExecutorTier`, `cheapestEligibleExecutors`, `executorDisabled` and the
`AgentExecutorConfig` shape they read — lives in a leaf module, so `fleet-service` and `history-service`
stop taking a compile-time dependency on the 3,370-line `agent-service.ts` just to read a pure policy, and
the policy gains a direct test surface (today it is only exercised through `AgentService`).

Source: `/sp:dev-review packages --focus all` (2026-09-25), architecture candidate C3. Keeps B2's
one-selector invariant (0543 R1): the funnel moves, it does not fork.

## Scope

**In:** new `packages/app/src/services/executor-tier.ts`; `agent-service.ts`, `fleet-service.ts`,
`history-service.ts` import lines; a new `packages/app/tests/services/executor-tier.test.ts`; the
`packages/config/src/index.ts:659` doc comment.

**Out:** any tier inference rule, tier rank or eligibility change; `TIER_RANK` / `isTierEligible` (stay in
`packages/domain`); the warn-once transition-shim state (`agent-service.ts:2873-2912`, scheduled for
removal — see cancelled task 0963); `executorFingerprint` (stays in agent-service).
