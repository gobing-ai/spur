# F84: Features board layout alignment, collapsible panels, and floating agent bar

## Goal
Modernize the Features Board web module layout and UI components to match Spur's Linear dark-canvas design language and History module layout patterns with collapsible floating navigation/metadata panels, readable width constraints, a refined dynamic action bar, and a foldable floating agent prompt bar.
## Scope
- In:
  - Center-aligned width-constrained layout container (`max-w-[1600px]`) and unified module header for the Features board.
  - Collapsible, dockable floating left panel for the Feature Tree hierarchy with toggle trigger.
  - Width-constrained container for Markdown body in both preview and MDEditor edit modes.
  - Collapsible right-side metadata drawer (folded by default with a docked trigger icon) showing frontmatter, timestamps, linked tasks, child features, and file path.
  - Refined stage-based dynamic action button group with primary/secondary visual hierarchy in the feature detail view.
  - Foldable floating agent prompt bar at the bottom of the viewport (~75% width expanded, spirit icon button collapsed) as a frontend UI component.
  - CSS styling following Spur's Linear dark canvas design tokens in `DESIGN.md`.
- Out:
  - Backend coding agent execution pipelines or live agent dispatch from the floating bar (UI only in this phase).
  - Modifications to backend oRPC router endpoints, database schemas, or CLI feature commands.
  - Altering existing feature state machines or FSM transition logic in domain packages.
