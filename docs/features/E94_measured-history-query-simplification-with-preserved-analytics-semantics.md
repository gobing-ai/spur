# E94: Measured history query simplification with preserved analytics semantics

## Goal

Reduce repeated history query and measure logic only when reproducible parity and workload measurements justify a smaller implementation.

## Scope

In scope: conditional W7 fixture parity and benchmark evidence, followed only on a go decision by removal of proven duplicate selector/measure definitions.

Out of scope: new caches/query builders, altered analytics semantics, production database experiments, mandatory consolidation after no-go, or upstream-engine extraction without a second consumer.

Conditional W7: compare raw/rollup/mart outputs and benchmark existing fixtures, then consolidate only equivalent selector/measure definitions if the documented benefit exceeds migration cost. Preserve freshness, filters, null/unknown meaning, import deduplication and materialized-first paths. No new cache/query-builder framework, external engine extraction or live-data benchmark mutation.
