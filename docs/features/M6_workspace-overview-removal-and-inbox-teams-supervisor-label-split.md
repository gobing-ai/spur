# M6: Workspace Overview removal and Inbox/Teams supervisor-label split

## Goal
Make Workspace, Inbox, and Teams non-overlapping under the agent-role
mechanism: delete Workspace's duplicate Overview, split the two
"Supervisor" labels, and keep role as a value on `spur agent` — no new
`role` noun.
## Scope
- In:
    - Delete `apps/web/src/modules/workspace/OverviewTab.tsx` and its
      `WORKSPACE_TABS` entry (0599 §5.2). Fold the two unique fields
      (`workDir`, `model`) into the Teams Supervisor team header / member row.
    - Keep Workspace as a **lens** (scoped Team / Inbox / Tasks only).
    - Rename the Inbox `Supervisor` tab to a label that names the message
      filter (e.g. `Supervisor traffic`) so it no longer collides with the
      Teams Supervisor process tab (0599 §5.3).
    - Keep Teams and Inbox as separate modules (M4 D1 stands; Teams-absorbs-both
      is rejected).
    - Record the no-`role`-noun recommendation as the approach (0599 §6). If a
      machine-readable inventory is later needed, it is `spur agent roles`
      (a verb), and that is a separate ADR-051 consent item — not this feature.
- Out:
    - Adding a `role` CLI noun (map open question 4; 0599 recommended no).
    - Merging Inbox into Teams, or Workspace into Teams.
    - `TasksTab` / `JobsTab` work (I6 deferred).
    - Role-vocabulary or `--agent` selector changes (B2 / M5).
    - New board modules.
