# A35: CLI two-level surface conformance: flatten noun-group-verb breaches and enforce command depth

## Goal

Every public command is exactly `spur <noun> <verb>` (ADR-051 amendment, 2026-10-17), and a test
keeps it that way. Today five commands break the rule: three grandfathered nested groups and two
that the ADR's list missed. Nothing stops new ones.

## Scope

- In: flatten `workflow commit-guard`, `agent dogfood`, `history anatomy` and `task batch-plan task-children` with the mechanical `<group>-<sub>` rename, keeping one-release deprecated shims; delete the hidden `builder pr` dispatcher; add a `buildProgram()` command-depth guard test; migrate source, bundled workflows, rules, `sp` plugin skills/commands, `docs/help`, design satellites and the ADR-051 amendment.
- Out: the top-level `init|maintain|migrate|serve|status` back-compat aliases of `spur self <verb>`; `spur self exec <action>` (open named operand, one grammar); closed single-grammar mode operands (`task gate|residual|wrapup|deps|sections`); merging `history anatomy-*` verbs; removing the deprecated shims (follow-up task).

## Acceptance Criteria

```gherkin
Feature: CLI two-level surface conformance: flatten noun-group-verb breaches and enforce command depth

  Scenario: R1 — no public command sits below a verb
    Given the CLI built by buildProgram()
    When the command-depth guard walks the tree
    Then no non-hidden command is at depth 3 or more, and hidden depth-3 commands are only the allowlisted deprecated shims

  Scenario: R2 — flattened verbs keep their contract
    Given each former nested sub-command
    When its flattened `<group>-<sub>` verb runs with the same flags
    Then stdout, --json output and exit code are unchanged, and the old form still works with one stderr deprecation line

  Scenario: R3 — callers and docs use only the flat verbs
    Given the repository after migration
    When the stale-form regex runs over plugins, config, packages, apps, docs/help, docs/design and AGENTS.md
    Then only the deprecation shims, their tests and dated ADR/governance history match
```
