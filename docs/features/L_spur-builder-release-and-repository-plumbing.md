# L: spur builder release and repository plumbing

## Goal

Umbrella for every `spur builder` capability: the release and repository plumbing noun that bumps
versions, drops tags, publishes packages, drives the pull-request review spine and reports branch
topology. Child features (`L1`, `L2`, …) own concrete increments; this node owns the shared
boundary so builder work lands in one place instead of scattering across unrelated features.

## Scope

- In:
  - Every `spur builder` verb and its service code: `bump-ver`, `drop-tags`, `publish`, `pr` (deprecated alias), and
    the verbs added by child features (L1: `show-branches`, `pr-status`, `pr-check`, `pr-open`, `pr-review`)
  - Slash commands and skills that are thin wrappers over builder verbs (`/sp:dev-pr-review`,
    `sp:pr-reviewing`, the `sp:spur-cli` builder reference)
  - Builder-owned workflows (`config/workflows/pr-review.yaml`)
- Out:
  - Adding a builder verb without the consent amendment in
    `docs/design/harness-surface-governance.md` §3
  - Generic git operations unrelated to release or review (branch deletion, history rewriting)
  - Skill-call history observability: the feature formerly at this id was cancelled and its scope
    lives under E9
