# H14: Plan and design document authoring contract

## Goal

Give plan and design Markdown documents a small, portable authoring contract so agents produce useful structure and existing files can be upgraded safely.

## Scope

**In:** Distinct plan/design templates and authoring references in `sp:spur-dev`; matching responsibility guidance in the project constitution and relevant init templates; a read-only `sp:spur-doctor` procedure that diagnoses legacy documents and proposes safe edits; link and template verification.

**Out:** New CLI verbs, UI/API changes, strict schema validation, and bulk rewriting historical documents. Existing plans and design satellites remain readable and may be upgraded individually.
