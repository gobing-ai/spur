# I: sp plugin

## Goal
Own the durable agent-facing harness delivered by `plugins/sp`: `/sp:dev-*` lifecycle orchestration,
the `sp:*` skill and subagent surfaces, thin command and hook adapters, and their parity with the
current Spur CLI contract.
## Scope
- In: `plugins/sp` skills, commands, subagents, hooks, orchestration guidance, structural tests,
  and `sp:spur-cli` reference parity with the source-local CLI.
- Out: runtime agent execution, runner/doctor behavior, process and session lifecycle, and executor
  selection; those belong to feature B. Historical mixed work remains under frozen feature H until
  an evidence-backed cleanup assigns each child to B or I.
