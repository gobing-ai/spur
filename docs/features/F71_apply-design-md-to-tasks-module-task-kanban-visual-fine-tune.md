# F71: Apply DESIGN.md to Tasks module (Task Kanban visual fine-tune)

## Goal
Apply the authoritative DESIGN.md (Linear-inspired design language: near-black canvas, four-step charcoal surface ladder, hairline borders, scarce lavender accent, disciplined typography) to the Tasks module of the Spur Board (`apps/web/src/modules/task-kanban/`) as a visual-layer fine-tune. This is a boundary-preserving styling refactor — no schema, DTO, transport, dependency, or module changes.
## Scope
- In:
    - Retoken TaskCard / KanbanColumn / TaskDetail / TaskFilters / NewTaskPanel onto DESIGN.md's surfaces via the existing `spur-*` tokens.
    - Enforce accent scarcity: single lavender accent (`--color-spur-primary`), no second chromatic accent; non-pill corners (cards use `rounded.lg` 12px, hairline borders — never pill).
    - Normalize the type hierarchy: body / caption / button hierarchy; display type irrelevant on the kanban surface.
    - Use module-scoped overrides as the fallback if the shared-token remap regresses other modules (teams, observability).
- Out:
    - Whole-board DESIGN.md overhaul (out of stated scope — Tasks module only).
    - Schema / DTO / transport / dependency / module changes.
    - Functional behavior changes; drag-and-drop / filters / SSE sync behavior untouched.
    - Teams / observability module retoken (verify only, no change).
