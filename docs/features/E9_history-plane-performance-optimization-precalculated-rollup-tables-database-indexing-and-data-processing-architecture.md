# E9: History plane performance optimization: precalculated rollup tables, database indexing, and data processing architecture

## Goal
Eliminate History Board loading latency by ensuring all 5 tabs (`Summary`, `Timeline`, `Sessions`, `Insights`, `Sources`) resolve in under 50ms against 1.7M+ message history databases. Achieve this through missing database indexes, routing all time-series and breakdown queries to precalculated rollup tables generated before the end of `spur history analyze`, and establishing `docs/design/history-data-processing.md` as the authoritative SSOT for the entire history ingestion, materialization, and query pipeline.
## Scope
- In:
  - Benchmark and root-cause analysis of each action and tab in the History module (`Summary`, `Timeline`, `Sessions`, `Insights`, `Sources`).
  - Migration adding targeted SQLite indexes across `history_message` (`(source, ts)`, `(model, ts)`), `history_tool_call` (`(session_id, seq)`), `history_board_message_5m` (`(bucket_start, model)`), `history_board_tool_5m` (`(bucket_start, skill_name)`), `history_board_session_stats` (`(started_at DESC, source)`), and `history_import_checkpoint` (`(source, updated_at)`).
  - Eliminating raw scans in `computeSummaryExtras` and `getSummary` by querying precalculated `history_board_tool_5m` for skill time series and `history_daily_stats` for previous period KPI comparisons.
  - Ensuring `refreshHistoryRollups` is invoked before the completion of `spur history analyze` and `spur history daily`, producing fresh materialized tables across all 11 rollup targets.
  - Authoring comprehensive architecture and data pipeline document `docs/design/history-data-processing.md`.
  - Adding automated performance regression tests in `packages/app/tests/services/history-board-service.test.ts` and `packages/domain/tests/analytics/history-board-rollup.test.ts`.

- Out:
  - Modifying external `@gobing-ai/ts-llm-jsonl-importer` parser internals.
  - Redesigning the frontend UI components or changing oRPC contract signatures.
  - Re-architecting non-history modules or unrelated SQLite tables.
