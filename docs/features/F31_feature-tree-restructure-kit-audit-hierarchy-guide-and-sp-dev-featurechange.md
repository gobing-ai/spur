# F31: Feature tree restructure kit: audit, hierarchy guide, and /sp:dev-featurechange

## Goal
Ship a dogfood-ready feature-tree restructure kit: verified root merge/reparent map, hierarchy design reference for agent skills, `/sp:dev-featurechange` (CLI-gated orchestrator), and a persisted old→new mapping file — ready for the operator to reload and dogfood the restructure without re-scanning the tree.
## Scope
- In:
  - Evidence-based audit of current feature roots (A–R) for redundancy / merge / reparent candidates (hypotheses such as B∪H and J∪K must be verified, not assumed).
  - Hierarchy design reference (principles + anti-patterns) consumable by existing skills (`sp:spur-cli` features, `sp:spur-dev`, decomposition).
  - Slash command `plugins/sp/commands/dev-featurechange.md` + skill protocol: dry-run plan → confirm → apply via `spur feature`/`spur task` verbs; cascade task `feature_id` edges; rewrite references only in root `docs/*.md` (not all of repo).
  - Persisted mapping SSOT: `docs/plans/feature-tree-restructure-map.md` (old id → new id / disposition).
  - Wayfinder investigation map under feature **F31** (under F3) until the kit is implementable.
- Out:
  - Executing the full live corpus rewrite as part of charting (operator dogfoods the command after reload).
  - Editing docs outside root `docs/*.md` (e.g. AGENTS.md, plugins/**, apps/**) unless a later destination redraw expands scope.
  - Automatic status sync redesign (now F82) except where restructure must preserve edges.
  - Cross-repo / superskill packaging of the command (install later via superskill once sp plugin ships it).
