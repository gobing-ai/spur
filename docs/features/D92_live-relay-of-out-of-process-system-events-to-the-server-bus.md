# D92: Live relay of out-of-process system events to the server bus

## Goal

Make workflow and rule events emitted by child CLI processes (agent-run task actions, `spur workflow run` inside an agent) appear live in the Board, by relaying persisted ledger rows written by other processes onto the server event bus, instead of only `message.*` rows.

## Scope

**In scope**
- Widen the ledger relay in `apps/server/src/modules/events/index.ts` (today `message.*` only) to every row not emitted by this server process.
- Track the ids of rows this server process persists from its own bus (in memory, no migration) so the relay skips them, and make the tap and catch-all skip relayed payloads so a relayed row is never re-persisted.
- Retire the stale v1 scope-limit comment at `apps/server/src/serve.ts:555-563` and update docs/design/observability-contracts.md.

**Out of scope**
- Rerouting task actions to in-process execution.
- A new IPC transport (forbidden by AGENTS.md coordination rule).

## Acceptance Criteria

```gherkin

  @core

    Given spur serve is running and a board task action spawns an agent that runs spur workflow run

  Scenario: R2 — The server never re-emits its own rows

    Then the row is not emitted a second time on the bus

```
