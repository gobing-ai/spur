# K43: Gateway as cross-project hub: one MCP entry per agent and a cross-project daily view

## Goal

Use the always-on gateway as the single integration point: each supported coding agent gets one MCP entry pointing at the gateway root, and the daily summary can span all local projects without the gateway holding state.

## Scope

**In scope**
- Install-time wiring of one stdio gateway MCP entry (`spur mcp --gateway`) shipped in `plugins/sp/mcp.json` and written per agent by `superskill install sp` (Superskill owns adapters).
- Cross-project daily view: `spur history summary --all-projects`; running projects read through the gateway (`/api/health`, `/api/events/history`), stopped ones marked from registry state and never woken.

**Out of scope**
- Gateway persistence.
- Remote projects.

## Acceptance Criteria

    Then it summarizes each project state and recent events, and marks stopped or unreachable projects
