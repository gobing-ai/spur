# M2: Teams residual polish for release (post-M1)

## Goal
Close the remaining Teams UX and process-watchlist gaps left after M1 so the board is release-ready: Attach actually opens Terminal on a member, bulk team Up/Down is available without the Roster, registry runs are filterable/grouped, and dead selection state is removed.
## Scope
**In scope:**
- Wire ProcessesTab Attach → TerminalTab local selection (listen for `teams:attach-process`, resolve team+member, switch/select).
- Surface team Up/Down bulk controls in the Teams UI (toolbar or Processes header), calling existing `/api/team/:team/up|down`.
- Optional filters on the Process watch list (source, running-only, team).
- Tag `teamId` on supervised spawns when known; group/filter registry rows by team.
- Remove or hollow-out dead `TeamsContext` selection API if nothing consumes it.
- Shared `useTeamsData` (or equivalent) to dedupe `/api/team/teams` polling across Terminal/Processes.

**Out of scope:**
- Full PTY / xterm.js terminal.
- Deep agent-loop stdin redesign.
- Observability OS-tree inventory redesign.
- Remote/multi-host process tracking.
- Messages per-member filter (defer until volume justifies).
