# I1: sp plugin hands-off ready

## Goal
Make the `sp` plugin hands-off ready for the normal development loop: turn an idea
into a checked feature/task batch, execute tasks through existing pipelines, wrap
up completed work with learning/metrics capture, and advance the feature through
legal lifecycle edges without bypassing Spur guards.

## Scope

- In scope: `/sp:dev-idea`, `/sp:dev-wrap`, `/sp:dev-wrapall`, idea/wrap-up workflow
  YAMLs, gate-checklist and cross-cutting references, structural plugin tests,
  checkpoint writes, learning/metrics capture, and guarded feature lifecycle
  advancement.
- Out of scope: standalone PM skills or commands, new lifecycle workflows, bypassing
  `spur` CLI guards for task/feature corpus writes, branch merge/delete automation
  without HITL confirmation, and bumping the shipped plugin manifest before the
  remaining release defects are closed.
