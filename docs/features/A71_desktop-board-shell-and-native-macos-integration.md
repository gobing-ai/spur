# A71: Desktop Board shell and native macOS integration

## Goal

Provide a native desktop host for the existing Spur Board, preserving the child server as the sole database owner and validating the packaged application on macOS.

## Scope

- In: thin Electron shell, explicit packaged project selection, isolated renderer, compiled server and CLI companion assets, macOS startup and shutdown validation.
- Out: new agent runtime, mobile app, key storage, multi-tenant execution, signing/notarization, and Windows/Linux native verification.

Feature: Desktop Board shell

    When it starts outside the checkout
    Then config and schema assets resolve and health reports ok
