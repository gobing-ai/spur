# G6: Projects and agent fleet unification design

## Goal

### Destination

Produce an evidence-backed design and migration contract that replaces Workspace, Inbox, and Teams with project-scoped agents, orchestration, and a complete Board command/result loop.

## Scope

- In: design and executable investigations of project/worktree identity, agent roles and lifecycle, durable inbox delivery and outcomes, rest/GTD strategy and capacity, Projects UI and global input, and retirement/migration of team-based surfaces.
- Out: production implementation in this map, a new broker or daemon, cloud orchestration, cross-project scheduling, dynamic strategy plugins, and unrequested changes to existing feature statuses.
