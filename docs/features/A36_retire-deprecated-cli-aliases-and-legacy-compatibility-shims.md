# A36: Retire deprecated CLI aliases and legacy compatibility shims

## Goal

Remove surfaces kept only for backward compatibility — the hidden `spur self daemon` alias, the five hidden legacy top-level nouns, and the fleet legacy member-id fallback — after migrating every internal caller, so the CLI and fleet code carry one spelling each.

## Scope

**In scope**
- Remove `spur self daemon <install|uninstall|status>` (`apps/cli/src/commands/self/daemon.ts:132`).
- Audit and migrate internal callers (project-start spawn argv at `packages/app/src/services/project-start.ts:466` — the one live runtime caller; the LaunchAgent plist already uses `self serve` — scripts, workflows, plugin docs, help fixtures) of the hidden legacy nouns (`init`, `maintain`, `migrate`, `serve`, `status`), then remove them (`apps/cli/src/index.ts:323-327` plus the boot-free fast path at `:144,168`).
- Retire the ADR-126 A4 legacy member-id fail-closed guard (`packages/app/src/services/fleet-service.ts:495-519`) and `legacyMemberLocalId`, behind a one-time preflight over every registered local project database proving no recorded runs use legacy ids.

**Out of scope**
- Removing any visible noun or verb.
- Changing daemon behavior.
