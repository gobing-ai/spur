## 0659. History-anatomy cache helper: semantic artifact digest, invalidation matrix, structure gate, atomic publish

### Background

ADR-079 makes cache validity a **derived fact**, not a stored claim: a cached daily report is
reusable only for its model-authored half, and only when a freshly derived semantic digest of the
analyze artifact plus the contract/skill/workflow logic digests all match what the cached report
recorded. That comparison, the structural checks on a candidate report, and the atomic replacement
of a published report are deterministic file/hash/schema work — they belong in one dependency-free
script, not in workflow prose or a model prompt.

**Verified against the tree on 2026-08-24:**

| Claim | Evidence |
| --- | --- |
| A plugin-shipped script needs a committed `.mjs` twin, a manifest entry, and no Bun globals | ADR-065 (`docs/00_ADR.md:836-860`) |
| Twins are generated by `superskill script convert sp <rel>` | ADR-065; `package.json:60` `build:scripts` |
| Shipped surfaces must invoke via `node "$(superskill script path sp <rel>.mjs)"`; `bun plugins/sp/scripts/<rel>` is forbidden | ADR-065 |
| The manifest shape is `{ rel, contract: standard\|repo-only, twin? }` | `config/plugin-scripts.json:5-13` |
| The gate is two-sided: stale/missing twins, unexpected twins, unlisted disk scripts, and forbidden repo-relative refs all fail | `plugins/sp/scripts/script-contract-check.ts:198-247` |
| `feature-sync-bounded.ts` is the pattern to mirror — pure exported functions + thin CLI entry, `node:` imports only, local types, `createHash` from `node:crypto` | `plugins/sp/scripts/feature-sync-bounded.ts:1-25` |

### Design

**WHAT.** One plugin-shipped, dependency-free script performing four deterministic jobs: semantic
artifact digest, cache-metadata comparison against the invalidation matrix, structural checks on a
candidate report, and atomic publication. Plus its `.mjs` twin and manifest entry.

**WHY.** ADR-079: cache validity must be re-derived, never trusted from a filename or timestamp. A
model asked to "check whether the cache is still valid" will sometimes say yes; a hash comparison
will not. Putting it in a script also keeps 0660's YAML to ordering and branching.

**WHERE.**

| Path | Change |
| --- | --- |
| `plugins/sp/scripts/history-anatomy-cache.ts` | new — the helper |
| `plugins/sp/scripts/history-anatomy-cache.mjs` | new — committed twin via `superskill script convert sp history-anatomy-cache.ts` |
| `config/plugin-scripts.json` | new `standard` entry with its `twin` |
| `package.json:60` | append `&& superskill script convert sp history-anatomy-cache.ts` to `build:scripts` |
| `docs/00_ADR.md` | ADR-065 amendment block (standard-script roster) |
| `plugins/sp/tests/history-anatomy-cache.test.ts` | new — unit tests over the pure functions |

**Mirror `feature-sync-bounded.ts` exactly:** pure exported functions for every decision, a thin
`runCli` doing the I/O, `node:` imports only (`node:crypto`, `node:fs`, `node:path`),
`process.argv.slice(2)`, and local types rather than imports from service packages.

**Frozen names (exported):**

```ts
export interface CacheIdentity {
    contractVersion: string;
    mode: 'daily';
    date: string;            // YYYY-MM-DD, local calendar day
    timezone: string;        // IANA zone id
    bounds: { since: string; until: string };  // normalized, inclusive, RFC3339
    sources: string[];       // sorted
}

export interface CacheProvenance {
    identity: CacheIdentity;
    windowState: 'provisional' | 'closed';
    generatedAt: string;
    validatedAt: string;
    artifactDigest: string;       // semantic digest of the current-window artifact
    baselineArtifactDigest: string | null;
    contractDigest: string;
    skillDigest: string;
    workflowDigest: string;
    coverage: Array<{ source: string; status: string; lastImportedAt: string | null }>;
}

export type CacheDisposition = 'hit' | 'miss' | 'forced-recompute';

export interface CacheDecision {
    disposition: CacheDisposition;
    /** Which invalidation-matrix row failed; empty on a hit. */
    reasons: string[];
}

export function semanticArtifactDigest(artifactJson: unknown): string;
export function decideCache(cached: CacheProvenance | null, current: CacheProvenance, opts: { recompute: boolean; dayClosed: boolean }): CacheDecision;
export function parseProvenance(reportMarkdown: string): CacheProvenance | null;  // null on absent/malformed — never throws
export function checkReportStructure(reportMarkdown: string): { ok: boolean; problems: string[] };
export function publishAtomically(candidatePath: string, targetPath: string): void;
```

**Semantic digest algorithm.** SHA-256 over `JSON.stringify` of the artifact canonicalized as
`selectorDigest` (`artifact.ts:240-263`) canonicalizes a selector: object keys sorted recursively,
`undefined` normalized to `null`, arrays whose order is not semantic sorted. Excluded from the
material — and **only** these:

- `generatedAt` (changes every analyze)
- any absolute filesystem path
- the digest field itself

`population` (from 0657) **is** included: a change in true session count is a change in evidence.

**Invalidation matrix** — `decideCache` returns `hit` only when every row passes; each failing row
appends a human-readable reason:

| Row | Reason string on failure |
| --- | --- |
| identity tuple equality | `identity:<field>` |
| `artifactDigest` equality | `data-changed` |
| `contractDigest` / `skillDigest` / `workflowDigest` equality | `logic-changed:<which>` |
| provenance parsed | `provenance-unreadable` |
| coverage not narrower than cached | `coverage-degraded` |
| `windowState` equality (a `provisional` cache read once `dayClosed`) | `window-closed` |
| `opts.recompute` | disposition is `forced-recompute` |

**Structure gate.** `checkReportStructure` asserts the eleven section names in order, the nine
per-finding fields on every findings row, the absence of `TODO` / placeholder / empty section
bodies, and that every evidence-ledger claim carries an anchor. It reads the frozen vocabulary from
0658's `references/report-contract.md` — do not re-declare the section names here; a second copy is
a second source of truth.

**Atomic publication.** Write the candidate to `<target>.tmp` in the same directory, `fsync`, then
`renameSync` onto the target. Same-directory rename is the atomicity guarantee; a cross-device
rename is not atomic. Never write the target in place. On any gate failure the tmp file is removed
and the target is untouched.

**Anti-patterns — do not implement.**

- Do **not** include `generatedAt` in the digest material, and do **not** exclude anything else.
  Over-excluding makes two different evidence sets hash equal — a silent stale-cache bug.
- Do **not** derive validity from mtime, filename, or `generatedAt`. That is precisely what ADR-079
  forbids.
- Do **not** throw on malformed cache frontmatter. `parseProvenance` returns `null`; the caller
  treats it as a miss with reason `provenance-unreadable`.
- Do **not** put finding, remediation, severity, or ranking logic in this script. It performs file,
  hash, and schema work only.
- Do **not** import from `packages/` — the plugin tree ships without the monorepo.
- Do **not** use `Bun.*` globals; the twin must run under bare `node`.
- Do **not** write the published target in place or via a cross-device rename.

**Cross-task.** Depends on 0657 for `population` (part of the digest material) and on 0658 for the
frozen section/field vocabulary the structure gate asserts. Leaves for 0660: the four exported
entry points and the `CacheDecision` shape the workflow branches on.
