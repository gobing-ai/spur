## 1005. W3 workflow progress --profile and history report --anatomy absorb profile and anatomy scripts

### Background

Wave W3. workflow-step-profile (459 LOC) and history-anatomy-cache (1152 LOC) carry workflow/history-domain logic in the plugin, far over the ADR-130 glue budget.

Implements: R6 — Refactor lands in independently revertible waves; R8 — sp skills, commands and workflows track every CLI move

Source: ADR-130, harness-surface-governance §2, docs/plans/A9-script-placement-migration.md.

**Refine corrections (2026-09-28)**
- "`spur workflow progress <run-id> --profile` (C5)" → the profile is per-workflow over `--last N` runs with `--window`, composed from `spur workflow trace --json`; `workflow progress` (`apps/cli/src/commands/workflow.ts:1666`) is per-run → resolution: C5 is not a fit and is left unexercised; a future per-workflow verb needs fresh consent.

### Design

**What.** Surface-neutral relocation: logic → `packages/app`, delivery → generated lib bundles, scripts → glue.

**Frozen names.** `packages/app/src/workflow/step-profile.ts`, `packages/app/src/services/history-anatomy.ts` (function names unchanged from the scripts). Bundles `plugins/sp/lib/step-profile.generated.mjs` and `plugins/sp/lib/history-anatomy.generated.mjs` with `.d.mts`. Script entry names, subcommands and flags unchanged.

**Why.** ADR-130 glue budget; C5/C6 verbs don't fit the scripts' shape (see corrections), so the lib rule is the placement that needs no new surface.

**Where.** Above modules, `scripts/commands/bundle-plugin-lib.ts`, `plugins/sp/scripts/{workflow-step-profile,history-anatomy-cache}.{ts,mjs}`, `plugins/sp/tests/*`, docs in R5.

**Anti-patterns.** No new `spur` flag or verb. No change to `history-anatomy.yaml` commands. Bundles stay standalone (no `@gobing-ai/*` at runtime; `sp-plugin-standalone`). Do not hand-edit generated files.

**Handoff.** None; 1007 re-verifies the baseline.

### Plan

1. Move step-profile logic + tests to `packages/app`; bundle row; slim script; regenerate twin.
2. Move history-anatomy logic + tests; bundle row; drop artifact-digest bundle if orphaned; slim script; regenerate twin.
3. Update pins/docs (R5); remove baseline rows.
4. `bun run spur-check`, `bun run plugin-smoke`, `spur rule run --rule sp-script-placement`.
