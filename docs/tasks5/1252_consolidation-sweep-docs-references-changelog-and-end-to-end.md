### Design

Chosen: one sweep after the behaviour tasks, so references are rewritten once against final behaviour. A repo-wide absence test makes regressions fail the feature gate.

Rejected:
- Per-task doc edits only: they leave cross-cutting references stale.
- An rg step in the gate script: it is untested and easy to drift.

Invariant: authority docs are updated at their owners per the constitution, and derived docs are not patched over authority (`sp:doc-evolve`).

Frozen names: `repo-wide-tests/workflow-consolidation-absence.test.ts`. Allowlist constant `HISTORY_ALLOWLIST: ReadonlyArray<{ glob: string; reason: string }>`.

- Docs:
  - docs/03_ARCHITECTURE.md;

  - docs/00_ADR.md (the ADR-142 status and ADR-119 consequence note only; earlier decisions keep their history);
  - the docs/design satellites from the Background inventory, minus the ones a behaviour task already rewrote.
